Practical Guide to Async Rust and Tokio | by Oleg Kubrakov | Medium
December 2, 2024 - Tokio implements a cooperative event loop, which means Tokio tasks should voluntarily yield control; otherwise, the entire runtime can be blocked. There is no tool that can identify functions that do not cooperate, and the compiler does not help either. This means you have to be extra careful when using any synchronous library in async code.
