# Component inventory

Sizes are CSS px at a 1440-wide window. Token names refer to `tokens/tokens.json` (`color.*`, `radius.*`, `motion.*`; Tailwind names in parentheses).

Conventions everywhere:
- **Control heights** are 24 / 28 / 32 / 40 (xs/sm/md/lg). Icon buttons are square at those sizes. The default is 32.
- **Radii by height:** a 24px control → 6, 28 → 7, 32 → 8. Popover items use 8, popovers 12, dialogs 12, the search palette 20, the composer 14.
- **Hover** is `fill-ghost-hover` (5% ink / 7.5% white). **Selected** is `fill-ghost-selected` (10% / 15%). Neither has a border change.
- **Focus-visible** is `shadow.focus` (1px inset page-colored gap + 1px blue ring + 6px glow). Inputs show it on focus; buttons only on keyboard focus.
- **Text colors:** primary for content, secondary for nav/labels at rest, muted for descriptions, placeholders and meta.
- **Weights:** body 360 (`regular`), labels/badges 460 (`medium`), section headings and titles 540 (`semibold`). Prose bold is 560.
- **Icons** are 16px in menus and controls, 20px in nav rows and composer buttons. They are outline glyphs.
- **Button press feedback:** box-shadow transition 60ms `ease-standard`, plus a spring scale of 0.99 (`ease-spring`).

## ChatGPT provider sign-in

On a server, the Add ChatGPT subscription step shows a copyable one-time code (`font-mono`, title size, tracked letters), the OpenAI verification link and an Open OpenAI button while authorization is pending. A spinner reports waiting, a footnote gives the 15-minute expiry and device-login prerequisite, and the introduction explains that everyone using the provider shares the admin's plan. Local desktop sign-in keeps its browser callback.
