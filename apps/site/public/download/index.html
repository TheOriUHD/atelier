Installing it
  1. Open the disk image and drag Atelier to Applications.
  2. Open Atelier from Applications. The build is signed and notarized, so it opens like any other app. Keep it there: that is how it updates itself.

Prefer a server?

For the web app, several people on one install, or one place for your data. Desktop apps can connect to it too.

  • Docker image for x86-64 and ARM64, with Caddy for HTTPS.
  • Invite codes and passkeys, keys encrypted at rest, one data folder to back up.
  • Never runs commands on the server. Code in a browser uses a desktop app’s folders.
Self-hosting guide Compose files 
# 1. copy deploy/compose.yaml and deploy/Caddyfile
#    and put your hostname in both
docker compose up -d

# 2. read the one-time setup token
docker compose logs atelier

# 3. open your site, create the admin, add a model

# later: update to the newest image
docker compose pull && docker compose up -d

The image is ghcr.io/theoriuhd/atelier.
