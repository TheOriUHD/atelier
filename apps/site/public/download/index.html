Atelier CLI · terminal app

Atelier in your terminal

A Code session where you already work: the same tools, permissions and models as the app, in any terminal and over SSH.

A program of its own, separate from the desktop app and from the server. It runs on its own with your own models and keys, or connects to an Atelier server.

curl -fsSL https://updates.atelierhq.dev/cli | sh
irm https://updates.atelierhq.dev/cli.ps1 | iex

Then run atelier in a project folder; the first start sets it up. It installs for you alone, brings its own Node.js and updates itself. x86-64 and ARM64.

Atelier Server · self-hosted

Prefer a server?

For the web app, several people on one install, or one place for your data. Desktop apps and Atelier CLI can connect to it too.

Not an app you open: it runs on a machine you keep on, and the apps, the browser and the terminal connect to it.

  • Docker image for x86-64 and ARM64, with Caddy for HTTPS.
  • Invite codes and passkeys, keys encrypted at rest, one data folder to back up.
  • Never runs commands on the server. Code in a browser uses the folders of a desktop app or Atelier CLI.
Self-hosting guide Compose files 
# 1. copy deploy/compose.yaml and deploy/Caddyfile
#    and put your hostname in both
docker compose up -d

# 2. read the one-time setup token
docker compose logs atelier

# 3. open your site, create the admin, add a model

# later: update to the newest image
docker compose pull && docker compose up -d

The image is ghcr.io/theoriuhd/atelier.
